# Agent front door: demo transcript

Real run, generated by `demo/run_demo.py`. The server runs as a subprocess and the callers talk to it over MCP stdio, the same way Claude Desktop, a ChatGPT connector, Gemini CLI or another Hermes would. The callers are fictional. The owner channel is a local file; nothing is sent anywhere.

## 0. Connect
Tools the door offers: `door_rules`, `list_facts`, `lookup_fact`, `request_call`, `ask_question`, `leave_lead`, `check_request`
